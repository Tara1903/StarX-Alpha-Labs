## 1. Overview & Positioning

**StarX Alpha Labs** is a premier technology and software engineering company building modern digital products, intelligent applications, and custom technology solutions for businesses.

We combine sub-second web performance, robust cloud architectures, and domain-grounded artificial intelligence to deliver high-concurrency platforms that drive measurable commercial advantage.

### Core Business Scope
- **Software Engineering**: Full-stack web and enterprise platform architecture.
- **Web & Mobile Application Development**: High-performance progressive web apps, corporate portals, and interactive digital experiences.
- **Custom Business Software**: Operations management systems, real-time dispatch dashboards, and internal business tooling.
- **AI Solutions & Applications**: Domain-grounded Retrieval-Augmented Generation (RAG), vector search pipelines, and workflow-embedded intelligent features.
- **Systems Engineering**: High-throughput microservice backends, database schema optimization, and distributed systems.
- **API Development & Integrations**: Resilient REST/GraphQL APIs, third-party webhook pipelines, and enterprise middleware.
- **E-Commerce Solutions**: Sub-second headless storefronts, custom visual configurators, and localized payment infrastructure.
- **Technology Consulting**: Architecture reviews, technical due diligence, security hardening, and replatforming strategies.
- **Architecture, Deployment & Maintenance**: Zero-downtime CI/CD pipelines, SLA-backed maintenance, and infrastructure observability.

## 2. Specialized Technical Divisions

To deliver depth of technical specialization while maintaining end-to-end architectural cohesion, **StarX Alpha Labs** operates across three specialized technical units:

1. **STARX DIGITAL** (`/divisions/starx-digital`):  
   Corporate web presences, digital storefronts, high-conversion landing pages, and progressive web apps engineered with sub-second response times.
2. **STARX SYSTEMS** (`/divisions/starx-systems`):  
   Enterprise web applications, business-specific portals, mission-critical operational tools, and scalable API integrations.
3. **STARX AI SOLUTIONS** (`/divisions/starx-ai-solutions`):  
   Domain-specific AI engines, private pgvector pipelines, and intelligent software features embedded directly inside custom platforms.

---

## 3. Strict Ecosystem Separation: StarX Alpha Labs & STARX FLOW

**StarX Alpha Labs** operates in coordination with, but in complete architectural and commercial independence from, **STARX FLOW**:

- **StarX Alpha Labs**: Bespoke software engineering, custom enterprise codebases, and tailored technology platforms.
- **STARX FLOW**: An independent commercial business automation platform providing turnkey AI receptionists, CRM automation, and omnichannel messaging.
- **Architectural Boundary**: 100% decoupled databases, isolated authentication providers, independent hosting environments, and distinct legal/administrative ownership. Zero customer data or tokens are ever shared across boundaries.

## 4. Technology Stack

- **Framework**: [Next.js 16.4.6](https://nextjs.org/) (App Router with Turbopack)
- **Runtime**: [React 19.0.0](https://react.dev/)
- **Styling**: [Tailwind CSS v4.0.0](https://tailwindcss.com/)
- **Visuals & 3D**: [Three.js](https://threejs.org/) & [@react-three/fiber](https://docs.pmnd.rs/react-three-fiber/)
- **Animation Primitives**: [Motion](https://motion.dev/)
- **Database & Auth**: [Supabase](https://supabase.com/) & PostgreSQL (with Row-Level Security)
- **Type Safety**: [TypeScript 5.8.2](https://www.typescriptlang.org/) with strict compiler enforcement
- **Icons**: [Lucide React](https://lucide.dev/)

## 5. Development & Scripts

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Run TypeScript type checking
npm run type-check

# Run ESLint validation
npm run lint

# Build production application
npm run build

# Start production server
npm start
```
